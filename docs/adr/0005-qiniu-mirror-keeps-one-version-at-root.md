# 七牛空间根目录只留每个身份的最新版，旧版进 `history/`

GitHub Release 在国内的下载速度是这条发布链路的瓶颈，所以每次发布后把产物镜像到七牛 Kodo。镜像的空间布局必须先定死，否则"哪个是最新"会变成第二个真相来源：根目录放当前每个身份（插件/平台/设备；工具链是目标三元组）的最新文件，被本版替换掉的旧文件移到 `history/<发布 tag>/<文件名>`，根目录的 `index.json` 按空间的**实际列举结果**重算。

## Considered Options

- **根目录一直累积，文件名里已经带版本**：否决。根目录会长成几百个文件，"最新"只能靠客户端自己挑；也没有清理的入口。
- **`index.json` 由本地 `dist/` 生成**：否决。本地目录和空间状态会在失败重试、手工补传之后分叉，索引一旦声称一个不存在的文件，客户端就拿到 404。
- **`history/` 按版本分目录**（`history/<版本>/<文件名>`）：否决。全量发布里各插件的版本号互不相同，没有单一版本可以当目录名；而且归档的 `SHA256SUMS` 属于"那次发布"，不属于某个版本号。统一成 `history/<发布 tag>/`，文件与它的校验和同处一目录。
- **`history/` 按插件分目录**（`history/<插件>/<tag>/`）：暂时否决。多一层路径没有换来可用的能力。
- **镜像失败就判发布失败**：否决。GitHub Release 已经是权威产物，镜像只是加速；反过来把镜像的可用性抬成发布的门槛，等于用一个可选项否决主链路。

## Consequences

- `index.json` 是根目录的导航文件，也是"现在该给新安装什么"的唯一答案；`docs/plugins.md` 仍然存在，两者并存意味着两份目录真相，收敛方向是 ADR 0003 的 `catalog/v1` 静态 JSON，届时 `index.json` 迁进去即可，格式不用改。
- 根目录的 `SHA256SUMS` 只覆盖**最近一次发布**的文件，全量校验以 `index.json` 里的逐文件 `sha256` 为准。保留文件如果换了来源、sha256 未知，字段为 `null`，不假装知道。
- 单插件发布只会移动它自己的旧文件，其它插件的当前包留在根目录；重跑一个更旧的 tag 时，根目录已有的更新版本不会被降级覆盖（脚本会打 `::warning::`）。
- 同一次运行里同一身份出现多个版本（构建目录里留了手抄的旧文件）时只上传最新的那个，其余按被取代处理、进 `history/`；否则根目录会同时出现同一插件的两个版本。
- `index.json` 描述本仓库的产物（插件包、工具链归档、发布公钥）**以及 svcd 本体**。`svcd[]` 由 CI 从 `plugin-manager` 的最新稳定 release 拉取后与包同置根目录，`svcd_sums_url` 指向根目录 `SHA256SUMS`；`release_asset` 在 `catalog_source = qiniu` 时优先读它，缺 `svcd` 小节才回落 GitHub。
- 这是一次有意的信任让步：宿主用同一份 `SHA256SUMS` 验归档，镜像同时持有字节与哈希，因此它可以决定「升到哪一版」——伪造不了字节（改不了哈希），但可以让升级停在自洽的旧版。真正的修复是给 svcd 的 release 加签名、由宿主验签；在那之前，`catalog_source` 就是「是否信任镜像选版本」的开关，默认仍是 `github`。
- 空间域名可以是 http：脚本照配置的 base 生成链接，不为「应该上证书」擅自改成 https（改了就等于指一个证书开不出来的地址）。商店侧的规则是「抓列表用什么协议，就要求下载用什么协议」——https 的列表不许指向 http 的包，http 的列表则一致地用 http。签名保证字节，不保证目录，这点写在使用文档里而不是靠默认值隐藏。
- svcd 的发布发生在另一个仓库，本仓库收不到它的 tag：`plugin-manager` 的发布流程在 `publish` 成功后用 `repository_dispatch`（`svcd-released`，payload 带 tag）通知 `mirror` 工作流，镜像因此是发布驱动的，而不是定时轮询。发布流程的 `qiniu` job 与它共用 `concurrency: qiniu-mirror`——`index.json` 是读-改-写，两个写入者重叠就会互相覆盖。
- Kodo 边缘默认把对象缓存一年，根目录的 `index.json` / `SHA256SUMS` 因此每次写完都要调 CDN 刷新；不清的后果不是报错，而是商店拿到旧索引后按「不比手里这份旧」规则回落到 GitHub——静默、且看起来像配置没生效。刷新失败只警告，因为发布本身已经完成。
- `history/` 无人清理，空间容量靠发布频率和人工维护；七牛的免费额度是每月 10GB 标准存储，外网流出按量计费，所以"镜像节省的是下载时间，不是账单"。
